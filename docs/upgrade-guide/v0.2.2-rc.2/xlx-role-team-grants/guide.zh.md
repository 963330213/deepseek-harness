# 团队委派按 XLX 角色授权

[English](guide.md) | 中文

## 变更

此前会话可以委派给任何启用的成员。安装 XLX Auth 后，普通角色初始没有成员授权。内置 `admin` 角色初始授权全部成员，也可以限制为指定成员。对于授权受限的会话，继续历史任务前需要重新委派未记录成员标识的子智能体。

## 迁移

1. 备份 XLX Auth 的 SQLite 数据库，同时升级 `dsh-xlx-auth` 和 `dsh-xlx-agent-team`。XLX Auth 启动时会新增角色授权字段。
2. 在「用户权限 → 管理角色」中编辑角色，在「授权智能体」中勾选对应成员。为 `admin` 选择具体成员前，先取消「授权全部智能体」。
3. 使用受影响角色开始对话，确认主智能体只发现已勾选且启用的成员。
