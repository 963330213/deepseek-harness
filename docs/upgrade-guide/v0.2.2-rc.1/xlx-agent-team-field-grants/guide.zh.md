# XLX 智能体团队：开放字段与 ZIP 上传

[English](guide.md) | 中文

## 变更

可选的 XLX 智能体团队插件要求同时配置物理表名和开放字段才能查询该表。旧设置和成员快照中的连接与表名仍可加载。没有开放字段的表无法查询或查看表结构。SQL 示例同样受字段限制，且不再支持子查询。

新增 Skill 只能上传 ZIP，已安装的 Skill 及其文件仍可使用。

## 迁移

1. 在 **智能体团队 → 编辑智能体 → 数据库** 中编辑已配置表的连接，在 **开放数据表** 选择物理表并勾选查询和 SQL 示例所需的字段。若直接编辑配置档案，在成员的 `capabilities.databases` 连接条目中添加 `columns` 字典，以 `tables` 中的物理表名为键。
2. 修改 SQL 示例，使其只使用开放字段和显式关联条件，并移除子查询。保存成员，重新委派任务，确认 `team_database` 的 `catalog` 列出开放字段。已有成员快照保留原配置，需要重新委派才能使用更新后的字段配置。
3. 添加或替换 Skill 时，将 `SKILL.md` 和所需资源打包成 ZIP，并在 **专属 Skill** 上传。
